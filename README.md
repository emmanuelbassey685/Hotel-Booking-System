# Rexona Hotel & Suite - Hotel Booking System

A responsive modular JavaScript hotel booking prototype built with HTML5, CSS3, JavaScript, JSON and localStorage.

## Run

```bash
npm install
npm run dev
```

Open the Vite URL shown in the terminal.

## Included

- Hotel home page
- Room search, filtering and sorting
- Room details
- Booking form and validation
- Booking calculation
- localStorage booking management
- Prototype payment workflow
- Booking confirmation
- Google Maps embed/fallback
- EmailJS-ready service module
- Responsive luxury-hotel UI
- Modular JavaScript architecture

## API configuration

Open `src/js/config.js` and add your public configuration values.

Do not place private payment secrets in frontend JavaScript or localStorage.

For a real payment integration, payment initiation and transaction verification should be handled by a secure backend/serverless function.
